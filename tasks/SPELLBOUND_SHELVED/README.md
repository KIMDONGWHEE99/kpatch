# Spellbound & Shelved 한글패치

Steam 빌드 25274913의 Windows 한국어 패치 1.0.1을 제작하여 사용자가 지정한 Steam 폴더에 적용했습니다. Steam에서 평소처럼 실행하세요. 기존 언어 설정이 있으면 메뉴에서 한국어를 선택하세요.

메뉴·설정·도움말·대사·업적·업그레이드·결과·개발 화면, 책 제목 2,625개와 일반 등장인물 이름 34개를 한글화했습니다. 원본 로고와 제작진·실존 게스트 이름 등은 유지했습니다.

업데이트의 새 설정·바닥 책 수·서가 채움 비율을 포함해 번역 키 311개를 적용했습니다. 새 후보 재추출·위치별 대조, 실제 GPU 대표 화면 16개 관찰, 최종 ZIP 설치·복구 시험 24건과 설치본 17개 파일의 해시 확인을 완료했습니다. 기존 저장 22개 파일과 이전 백업을 보존했습니다. 전체 플레이 시간과 모든 무작위 상황을 끝까지 시험한 것은 아닙니다.
