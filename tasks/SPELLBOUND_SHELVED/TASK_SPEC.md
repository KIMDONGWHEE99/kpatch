## 목표와 범위

사용자가 지정한 설치본의 Windows 한글패치를 제작한다. 메뉴, 도움말, 업적, 업그레이드, 등장인물 대사, 책 제목 2,625개, 직접 표시 문구, 이미지 속 문구를 조사한다. 작업은 원본 사본에서 수행하며, 게임 규칙·수치·저장 형식은 변경하지 않는다. 공개 게시 요청은 없으므로 로컬 패키지 제공을 목표로 한다.

- Godot 4.7.1, GDScript 바이트코드 101, PCK 형식 4. Mono/IL2CPP와 Unity 글꼴 검사는 적용 대상이 아니다.
- 원본 17개 파일, 총 397,736,828바이트. `source_original/SPELLBOUND_SHELVED/steam_25171813`에 보존한다.

- GDRE 2.6.4로 스크립트 22개와 자산 51개를 복구했다. 실패 0건. 손실 변환 1건은 편집기 Steam SVG의 벡터 재구성이며, 원본 픽셀을 따로 확인하고 배포에는 원본 자산을 보존했다.

## 수정과 검증 계획

1. PCK를 변경 없이 재저장하고 해시를 비교한다. 소규모 한국어 표본·글꼴·언어 선택을 격리 사본에서 실행한다.
2. 한국어 언어 슬롯, 번역표와 책 제목표를 추가한다. 직접 표시 문자열은 원래 코드 위치를 기록해 수정한다.
3. Noto Sans KR를 기존 글꼴의 한글 대체 글꼴로 연결한다. Godot 동적 글꼴의 문자 지원, 실제 표시 경로와 화면 잘림을 검사한다.
4. 후보 PCK를 독립적으로 다시 추출하고 위치별 번역, 원본 보존 영역, 코드 재분석 결과를 대조한다.
5. 검수 PCK에서만 제품명을 바꾸고 Steam 확장 자동 로딩을 해제한다. 사용자 저장 경로와 검수 경로의 분리를 실제 관찰한다. 원본 저장·설정·Steam 사용자 데이터의 실행 전후 목록과 해시를 비교한다.
6. 첫 화면·언어 선택·설정·새 게임·HUD·도움말·업그레이드·업적·종료와 결과 화면을 제작자가 관찰한다. 게임에 내장된 시험 옵션은 검수 사본에서만 사용한다.
7. 차이 패치의 정방향·역방향 해시와 최종 ZIP에서 꺼낸 설치기의 정상·중복·변조·부분 상태·제거·실패 복구를 시험한다.
