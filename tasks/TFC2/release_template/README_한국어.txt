TFC2: The Fertile Crescent 2 한국어 패치 1.0.0
대상: Steam 앱 4158610 / 빌드 25097525 / Unity 6000.2.9f1

1. 설치
게임을 완전히 종료한 다음 압축을 풀고, '한국어 패치 설치.cmd'를 실행하세요.
화면에 표시되는 게임 폴더를 확인한 뒤 Y를 입력하세요.
기본 검색 경로: D:\steam\steamapps\common\The Fertile Crescent 2
다른 위치에 설치했다면 TFC2.exe가 있는 게임 폴더를 직접 입력할 수 있습니다.

설치기는 대상 파일의 SHA-256(파일의 고유 지문)을 확인합니다.
Steam 빌드 25097525의 원본 또는 이 패치가 적용된 파일만 허용합니다.
게임 업데이트, 손상, 다른 패치로 인한 알 수 없는 파일은 수정하지 않고 중단합니다.
설치 중 컴퓨터를 끄지 마세요. 설치가 일부만 끝났다면 같은 설치기를 다시 실행하세요.

2. 언어 선택
이 패치는 게임의 영어(en) 언어 슬롯을 한국어로 바꿉니다.
게임 설정에서 '한국어'를 선택하세요. 다른 언어 슬롯은 변경하지 않습니다.

실행 코드 조합 문구 36종, 화면에 표시되는 자원 이름 9개를 한국어로 바꿨습니다.
메뉴, 설정, 도움말, 튜토리얼, 지도 편집기, 멀티플레이, 캠페인,
기술·건물·유닛·자원·임무·알림·개발/접근성 화면의 실제 표시 필드를 조사했습니다.
