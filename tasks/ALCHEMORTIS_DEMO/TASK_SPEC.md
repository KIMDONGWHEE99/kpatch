## 실행 검수

실행 전에 C# 코드와 프로젝트 설정에서 저장·설정·로그·Steam·오류 전송 경계를 조사한다. 검수 사본에서 저장을 작업 영역으로 격리하고 Steam 쓰기 및 오류 전송을 비활성화한다. 해당 변경은 검수 사본에서만 허용하며 파일·필드·메서드 차이를 기록한다. 실행 경로와 해시, 실행 전후 사용자 자료 해시를 수집한다.

검수 화면: 첫 화면, 설정·언어, 새 게임·이어하기, 캐릭터·도구 설명, 전투 HUD·알림, 튜토리얼·도움말·일시정지, 승패·결과·데모 종료. 없는 기능은 근거를 기록하고 미도달 화면은 미검증으로 남긴다. 실제 그래픽에서 한글 네모·잘림·겹침·태그 노출을 판독한다.
