SuperReap Demo 한국어 패치 1.0.1
================================

대상 게임
- Steam 앱: SuperReap Demo (App ID 4946910)
- 게임 빌드: 24989350
- Unity: 2022.3.62f3 / Mono

설치 방법
1. 게임을 완전히 종료합니다.
2. 이 폴더의 "한국어 패치 설치.cmd"를 실행합니다.
3. 표시되는 대상 폴더가 맞는지 확인한 뒤 Y를 입력합니다.

제거 방법
1. 게임을 완전히 종료합니다.
2. "한국어 패치 제거.cmd"를 실행합니다.
3. 원본 파일 SHA-256이 모두 복원되었는지 자동 검사됩니다.

안전 장치
- 지원하는 원본·이전 패치 파일의 SHA-256이 아니면 설치를 중단합니다.
- 이미 설치된 상태에서 다시 실행해도 파일을 중복 변경하지 않습니다.
- 설치와 제거 모두 결과 파일을 먼저 임시 폴더에 만든 뒤 SHA-256을 검사합니다.
- 게임 업데이트 뒤에는 무리하게 설치하지 말고 새 버전의 패치를 기다려 주세요.

한글화 범위
- Unity Localization StringTable 3개 언어 묶음
- 장면·프리팹의 TextMeshPro 및 Text 직접 문구
- YooAsset 설정·대화·Yarn 런타임 문구
- Mono 코드의 화면 문구, 조합 문구, 초 단위, 화면 표시 enum 이름
- 한글 글꼴과 실제 사용 글리프
- 설정, NEW 배지, 행운 룰렛 이미지 속 문구

의도적으로 유지한 표기
- Super Reap, Steam, Unity, FMOD, ZoomGames 등 로고·상표·저작권 이름
- 제작진 이름과 코드·리소스 식별자

검증 정보
- 분류 항목 10,019건, UNKNOWN 0건
- 한글 적용 대상으로 분류한 항목 2,314건
- 변경 파일 24개, 비변경 파일 420개
- 설치·제거용 VCDIFF를 생성 직후 역적용하여 후보·원본 SHA-256과 대조
- 설치기 격리 시험 통과: 원본, 중복 설치, 1.0.0 갱신, 부분 설치 재개, 변조 차단, 제거
- 최종 후보 배치 실행 종료 코드 0, YooAsset 목록과 Farm 장면 로드 확인

- 그래픽 후보 첫 화면에서 "데모 버전"과 "눌러서 계속하기" 한글 표시 확인
- 그래픽 후보 실행 로그의 한글 글리프 누락 경고 0건

1.0.1 변경 사항
- 1.0.0에서 한글이 네모(□)로 표시되던 TMP 글꼴 아틀라스 문제를 수정했습니다.
- 이미 1.0.0을 설치한 상태에서도 설치 파일을 실행하면 1.0.1로 갱신됩니다.

주의
- 이 패치는 게임 원본 파일을 포함하지 않으며 파일 차이만 배포합니다.
- 실제 플레이 화면은 PC 환경과 저장 데이터에 따라 달라질 수 있습니다.
- 그래픽 창을 띄운 전체 회차 반복 플레이 검수까지 완료했다는 뜻은 아닙니다.
- 게임이 업데이트되면 설치가 자동으로 중단될 수 있으며 이는 정상적인 보호 동작입니다.
