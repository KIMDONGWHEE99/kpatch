How Empires Work 한국어 패치 1.0.1
지원: Steam 빌드 26482667 / 개인용

1.0.0에서 세금 징수 후 진행되지 않던 결함을 수정했습니다.
진행 이벤트 이름 11곳을 원래 값으로 복구합니다. 표시 번역과 글꼴은 유지합니다.

게임을 종료한 뒤 Install.cmd를 실행하고 설치 폴더를 지정하세요.
기존 1.0.0 사용자: 기존 묶음의 Remove.cmd로 먼저 원본을 복원한 뒤 이 설치기를 실행하세요.
다른 패치 파일이나 지원하지 않는 업데이트에는 강제 적용하지 않습니다.
제거는 이 묶음의 Remove.cmd로 합니다. 원본 백업은 사용자 Local AppData의 HowEmpiresWorkKoreanPatch 아래에 보존됩니다.

이미 1.0.0에서 멈춘 저장에는 해제 이벤트가 누락돼 있습니다. 패치 교체만으로 저장이 자동 복구되지는 않습니다.
이번 사용자 환경의 저장은 별도 원본 백업·최소 항목 복구·실제 불러오기 검수를 거쳐 복구합니다. 이 일반 설치기는 저장 파일을 변경하지 않습니다.
전체 회차·모든 분기 완주 검수는 하지 않았습니다. 원본·파생 게임 자산 및 개인 저장은 이 묶음에 포함되지 않습니다.
