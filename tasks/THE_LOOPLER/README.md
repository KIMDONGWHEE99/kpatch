# The Loopler 한국어 패치

Steam 빌드 25262314용 한국어 패치 1.0.0을 `D:\steam\steamapps\common\The Loopler`에 적용하고 한국어로 설정했습니다.

한국어 표 1,331행·직접 문구·코드 문구 35종·게임 내 업적 47개의 이름/설명 연결·한글 글꼴·언어 선택 버튼을 적용했습니다. 설치 파일 76개와 원본 백업 7개를 확인했고, 저장·기존 설정은 언어 선택 이외 그대로입니다.

사용자가 추가 검수 중단과 마무리를 지시하여 결과 화면과 마지막 설정 전체 순회는 진행하지 않았습니다. G0~G8 전체 통과나 모든 분기 완주로 주장하지 않습니다. 게임/제작사 로고·키 표식·장식 글자·이전 홍보물 픽셀과 원본 음향은 유지합니다.
