## 조사와 검증

- GameTextLanguageSO 언어표, 장면·프리팹의 TMP 문구, 공용 자산·TextAsset, Assembly-CSharp의 모든 문자열·표시 enum·실행 중 조합 문구와 개발 화면을 위치별 조사한다.
- 이미지·스프라이트는 원본 객체 해시와 연결해 육안 판정한다. 오류와 새 항목은 UNKNOWN이며 대체 해석으로 해소하기 전 완료로 보지 않는다.
- 대량 번역 전에 재저장과 소규모 한글 출력·로딩을 시험한다. 전체 번역 문자와 Font·TMP 문자표·글리프·동적 모드·다중 아틀라스·재질·폴백 연결을 검사한다.
- 저장 코드와 설정·로그·Steam 쓰기 위치를 조사한 뒤 검수 사본에서 격리한다. 실행 경로와 후보 해시, 사용자 저장 전후 해시를 실제 수집한다.
- 첫 화면·설정·새 게임·안내·전투 HUD·기술/유닛 툴팁·일시정지·승패·데모 종료를 제작자가 검수한다. 미도달 화면은 NOT_RUN이다.
- 후보를 독립 재추출하고 위치별 기대 번역, 객체 수·ID·참조·필드 변경 범위, 태그 순서와 서식 인수를 대조한다. 알려진 결함을 넣어 검사기가 검출하는지 시험한다.
- G4·G5 통과 후 양방향 차이 파일과 해시 제한 설치기를 만든다. 최종 ZIP에서 꺼낸 설치기로 정상·중복·제거·변조·누락·부분 설치·교체 실패·강제 중단 복구·한글 공백 경로를 시험한다.
- 공통 PROC-01~08의 미구현 부분을 과거 PASS로 대체하지 않는다. 이번 게임의 독립 증거를 확보한다.
