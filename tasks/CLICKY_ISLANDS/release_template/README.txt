Clicky Islands 한국어 패치 @VERSION@
====================================

대상: Steam판 Clicky Islands, 빌드 26701014 (Windows)
개인이 만든 비공식 패치입니다. 원작의 저작권은 Karrot Games와 Pocketpair Publishing에 있습니다.

■ 설치
1. 게임을 종료합니다.
2. 이 폴더의 Install.cmd 를 실행합니다.
3. 게임 위치가 자동으로 나타납니다. 맞으면 [설치]를 누릅니다.
   찾지 못하면 [찾아보기]에서 "Clicky Islands.exe"가 있는 폴더를 고릅니다.
4. "한글패치 적용 완료"가 나오면 Steam에서 게임을 실행합니다.
   - Windows가 한국어이면 처음부터 한국어로 시작합니다.
   - 영어로 나오면 설정(톱니바퀴) → 언어 → "한국어"를 누릅니다.

■ 제거
Remove.cmd 를 실행하면 원본 파일로 되돌립니다. 저장 파일은 건드리지 않습니다.

■ 무엇이 바뀌나요
- 게임 폴더의 "Clicky Islands.pck" 한 파일만 바뀝니다. 실행 파일과 DLL은 그대로입니다.
- 게임에 비어 있던 한국어 칸을 채우는 방식이라 영어 등 다른 언어도 그대로 고를 수 있습니다.
- 한글 글꼴(Noto Sans KR)이 게임 자료에 추가됩니다.
- 저장 파일, 업적, Steam 설정은 바꾸지 않습니다.

■ 알아 두실 점
- 게임이 업데이트되면 설치기가 "게임 버전이 다르거나 파일이 변경됐습니다"라고 알리고 아무것도 바꾸지 않습니다.
  업데이트 전에 설치한 패치는 Steam이 파일을 새로 받으면서 사라질 수 있습니다.
- Steam의 "게임 파일 무결성 검사"를 하면 원본으로 되돌아갑니다. 다시 Install.cmd 를 실행하면 됩니다.
- 튜토리얼의 짧은 시연 영상 12종은 영어 화면을 녹화한 것이라 영상 속 글자는 영어입니다.
  영상 옆의 설명문과 목표는 한국어로 나옵니다.
- 게임 제목, 제작진 이름, 로고, 개발자 명령창은 영어 그대로입니다.
- 원작에 번역 항목이 없는 문구 일부는 원작처럼 내부 이름이 그대로 보일 수 있습니다.

■ 검수 범위
- 번역 1,078칸과 직접 문구 46개는 패치된 파일을 다시 풀어 전부 대조했습니다.
- 실제 화면은 첫 화면, 설정, 기본 화면과 툴팁, 항구, 섬 단계 상승, 임무 편지, 허수아비,
  항해 화면(특성·화석·유물·도전 과제), 게임 완료 창, 저장 불러오기를 확인했습니다.
- 시장, 가마솥, 화산, 후반 단계의 건물 화면 등은 화면으로 확인하지 못했습니다.
  전체 회차를 끝까지 플레이한 검수는 아닙니다.

■ 포함된 것
- Install.cmd, Remove.cmd, Patch.ps1, ChooseGame.ps1: 설치·제거 도구
- patches\: 원본과 패치본의 차이 파일(게임 원본 자료는 들어 있지 않습니다)
- tools\xdelta3.exe: 차이 파일 적용 도구 (Apache License 2.0)
- licenses\: xdelta3와 Noto Sans KR(SIL Open Font License 1.1)의 라이선스
- manifest.json: 지원하는 파일의 지문 목록
