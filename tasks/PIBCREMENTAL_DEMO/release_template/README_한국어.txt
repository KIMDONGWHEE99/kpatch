Pibcremental Demo 한국어 패치 1.0.0
대상: Steam 앱 4780080 / 빌드 25008003 / 게임 표시 버전 27.08.01

1. 설치
게임을 완전히 종료한 다음 압축을 풀고, '한국어 패치 설치.cmd'를 실행하세요.
화면에 표시되는 게임 폴더를 확인한 뒤 Y를 입력하세요.
기본 검색 경로: D:\steam\steamapps\common\Pibcremental Demo
다른 위치에 설치했다면 게임 폴더를 입력할 수 있습니다.

설치기는 대상 파일의 SHA-256(파일의 고유 지문)을 확인합니다.
위 빌드의 원본 또는 이 패치가 적용된 파일만 허용합니다.
게임 업데이트, 손상, 다른 패치로 인한 알 수 없는 파일은 수정하지 않고 중단합니다.
설치 중 컴퓨터를 끄지 마세요. 설치가 일부만 끝났다면 같은 설치기를 다시 실행하세요.

2. 번역 범위
영어·독일어 언어 슬롯을 모두 한국어로 채웠습니다.
게임에서 어느 언어 슬롯을 선택해도 한국어가 표시됩니다.
설정에는 '한국어 (영어)', '한국어 (독일어)'로 표시됩니다.
메뉴, 설정값, 튜토리얼, 대화, 건물, 강화, 자원, 툴팁, 환생,
탐험, 의상, 주스, 유물, 도전 과제의 게임 내부 데이터 및 예비 표시 문구를 번역했습니다.
게임의 아기자기한 분위기에 맞춰 Pib/Pibble은 '피블', Sap은 '수액',
Scrap은 '고철', Prestige는 '환생'으로 통일했습니다.
한글 글꼴은 Noto Sans KR을 사용하며, 원래 숫자·아이콘 글꼴은 유지합니다.

3. 의도적으로 남긴 표기
Pibcremental, Arcane Cabinet, Grab The Games, Discord 같은 게임명·상표,
제작진 인명·닉네임·곡명, URL, Cmaj13 화음명, CU3·S.N.A.F.U 등의 고유 약칭,
FPS·XP·PP 및 숫자 단위·조작 키는 필요한 곳에서 유지합니다.
이미지의 게임명·개발사 로고와 장식 낙서는 바꾸지 않았습니다.
Steam 상점·Steam 도전 과제 팝업처럼 게임 파일 밖에서 제공되는 문구는 이 패치의 대상이 아닙니다.
텍스트 레이어 번역과 이미지 픽셀 수정은 서로 구분합니다.

4. 제거와 복구
게임을 종료하고 '한국어 패치 제거.cmd'를 실행하면 지원 빌드의 원본으로 되돌립니다.
Steam의 '설치된 파일 → 게임 파일 무결성 검사'로도 원본을 복구할 수 있습니다.
게임이 업데이트된 경우에는 이 패치를 재설치하지 말고 해당 버전용 패치를 사용하세요.
이 설치기와 제거기는 저장 데이터 폴더를 수정하지 않습니다.

5. 검증과 제한
정적 검사 및 대표 화면의 그래픽 실행 검증 내용은 '검증보고서.txt'를 참고하세요.
모든 회차·모든 분기를 끝까지 플레이했다는 뜻은 아닙니다.
최초 공개 패치이므로 이전 공개 버전에서의 업데이트 시험은 해당하지 않습니다.

6. 배포 구성
원본 게임 파일은 포함하지 않습니다.
설치·제거 도구, 차이 패치(VCDIFF), 문서, 오픈소스 라이선스만 배포합니다.
게임 소유권과 저작권은 각 권리자에게 있습니다. 비공식 한국어 패치입니다.
