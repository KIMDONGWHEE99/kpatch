Cobalt Miner 한국어 패치 1.0.0 — 개인용
지원: Steam 앱4601880 / 빌드24347666 / Windows

메뉴·대사·설명397종517위치, 실행 모듈192필드, 이미지 문구12개와 한글 글꼴을 반영했습니다.
영어 언어 슬롯을 한국어로 바꿉니다. 설정에서 '한국어'를 선택하세요.
게임 수치·진행 규칙·저장 형식은 변경하지 않습니다.

설치
1. 게임을 종료합니다.
2. ZIP을 새 폴더에 완전히 풀고 Install.cmd를 실행합니다.
3. Cobalt Miner 설치 폴더를 선택합니다. 다른 빌드·변조 파일은 강제 적용하지 않습니다.
4. 완료 안내가 나온 뒤 Steam에서 게임을 실행합니다.
이미 제작자가 설치를 완료했다면 다시 설치할 필요가 없습니다.

제거·복구
Remove.cmd를 실행하고 같은 게임 폴더를 선택하면 원본으로 복원합니다.
설치가 중간에 끊겼다면 같은 ZIP의 Install.cmd 또는 Remove.cmd를 다시 실행하세요.
원본 백업과 진행 기록은 %LOCALAPPDATA%\CobaltMinerKoreanPatch\working_private 아래에 보관됩니다.
백업이 없더라도 지원되는 패치 파일은 역방향 차이 파일로 원본 복원이 가능합니다.
게임 업데이트 후에는 이 버전을 강제 적용하지 마세요.

확인 범위와 남은 항목
사용자의 요청에 따라 추가 화면 검수와 엔진 문구 조사를 종료한 개인용입니다.
확인된 번역 대상517위치·192필드의 누락0건, 위치별 후보 재추출·필요 문자·이미지 변경 경계 검사를 통과했습니다.
주요 대사107개, 설명20개, 주변 대사30개와 기재한 메뉴·설정·도입·엔딩·강화·표지를 판독했습니다.
전체 시설·도움말·예비 화면·전체 분기·전체 회차의 실행 검수는 완료하지 않았습니다.
엔진 내부·예외 문자열1237개는 실제 화면 표시 여부가 미확정이며, 미번역 문구가 전혀 없다는 뜻은 아닙니다.
게임 제목·제작사/제작진 이름·로고·모델 코드·수치 및 한국어 외 언어 슬롯 일부는 원래 표기를 유지합니다.
픽셀 문구는 광고판11장과 발전소 간판1장을 교체했습니다. 모든 그림·로고를 한글로 바꾼 패치는 아닙니다.

알려진 실행 관측
검수 사본에서 A엔딩→이어하기→빠른 종료 시 원본과 후보 모두 같은 접근 오류가 발생했습니다.
충분히 대기한 후보의 저장·엔딩·이어하기·종료 시험은 오류 없이 끝났습니다. 오류의 전체 발생 조건은 미확정입니다.
이전 B엔딩 검수 사본의 종료 시 그래픽 모듈 오류는 추가 원인 조사를 마치지 않았습니다.
전체 G0~G8 통과판이나 모든 환경에서 무오류를 보장하는 완성 검수판으로 표시하지 않습니다.
원본의 강화 설명 수치와 실제 동작이 다른 항목은 원문 뜻을 번역하고 게임 동작은 그대로 두었습니다.
