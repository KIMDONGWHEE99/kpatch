# Combolands 한국어 패치

최신 배포본은 한국어 패치 **1.0.1**입니다. Steam의 게임 위치를 자동으로 찾고 폴더를 선택하는 창을 추가했습니다. 번역은 1.0.0과 같으며 `D:\steam\steamapps\common\Combolands`에는 이미 적용되어 있으므로 다시 설치할 필요 없습니다. 대상은 Windows Steam 빌드 24989173, 게임 버전 1.0.6입니다.

다른 설치본에 적용할 때는 [패치 ZIP](../../release_output/COMBOLANDS_KOREAN_PATCH_1.0.1.zip)의 압축을 모두 풀고 게임을 종료한 뒤 `Install.cmd`를 더블클릭합니다. 창에 표시된 게임 폴더를 확인하고 **설치**를 누릅니다. 위치가 다르거나 비어 있으면 **찾아보기…**로 `Combolands.exe`가 있는 폴더를 선택합니다. 명령어 입력은 필요 없습니다.

제거는 같은 폴더의 `Remove.cmd`를 더블클릭하고 게임 폴더를 확인한 뒤 **제거**를 누릅니다. 원본 백업은 `%LOCALAPPDATA%\CombolandsKoreanPatch\working_private` 아래에 보관합니다. 지원하지 않는 게임 버전이나 변경된 파일에는 강제로 적용하지 않습니다. [설치기 개선 결과](../../validation/COMBOLANDS/ko_1.0.1/RESULT_REPORT.md).

최종 후보는 `ko_v010_c11`입니다. 자산 문구 1,833곳(번역 1,800곳·유지 33곳)과 코드 문구 25곳을 대조했고, 설치본 206개 파일과 원본 백업 8개를 확인했습니다. 설치 전후 사용자 저장·설정은 동일합니다.

제작 중 메뉴·설정·진행·상점·툴팁·승리·해금 화면을 확인했습니다. 사용자 요청에 따라 추가 플레이와 설치 실패 상황의 확장 시험은 중단했습니다. 최종 후보의 모든 화면이나 전체 분기를 검증했다는 의미는 아니며, 자세한 확인 범위는 [결과 보고서](../../validation/COMBOLANDS/ko_1.0.0/RESULT_REPORT.md)에 기록했습니다. 외부 사이트에는 업로드하지 않았습니다.
