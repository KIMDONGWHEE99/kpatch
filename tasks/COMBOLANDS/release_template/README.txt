Combolands 한국어 패치 1.0.1

대상: Windows Steam 빌드 24989173 / 게임 버전 1.0.6

설치 — 명령어를 입력할 필요 없습니다.
1. 게임을 종료하고 ZIP의 압축을 모두 풉니다.
2. Install.cmd를 더블클릭합니다.
3. 창에 표시된 게임 폴더를 확인하고 [설치]를 누릅니다.
   위치가 다르거나 비어 있으면 [찾아보기…]를 눌러
   Combolands.exe가 들어 있는 Combolands 폴더를 선택합니다.
4. 적용 완료 안내가 나오면 창을 닫고 Steam에서 게임을 실행합니다.
   별도의 언어 선택은 필요 없습니다.

게임 위치는 Steam의 기본·추가 라이브러리와 이전 패치 설치 기록에서 찾습니다.
여러 위치가 있으면 목록에서 선택할 수 있습니다.
위치를 모르면 Steam에서 게임 우클릭 → 관리 → 로컬 파일 보기로 확인합니다.

제거
게임을 종료하고 Remove.cmd를 더블클릭한 뒤 게임 폴더를 확인하고
[제거]를 누릅니다. 사용자 저장과 게임 설정은 변경하지 않습니다.
원본 백업은 %LOCALAPPDATA%\CombolandsKoreanPatch\working_private 아래에
게임 경로별로 보관하며 설치기에서 정확한 경로를 안내합니다.
설치 중 중단되었다면 같은 버전의 설치기를 다시 실행해 복구합니다.
업데이트되었거나 다른 내용의 게임 파일에는 강제로 적용하지 않습니다.

1.0.0 사용자는 다시 설치할 필요 없습니다. 번역 내용은 동일하며
1.0.1에서는 게임 폴더 자동 탐색·선택 창을 추가했습니다.

반영 범위
메뉴, 설정, 건물·아이템·효과 설명, 도움말, 의회·퀘스트, 승패·해금,
의견 양식과 기능 그림의 한국어 표시 및 한글 글꼴을 반영했습니다.
게임 제목, 제작사·Steam 로고, 제작진 이름과 기술용 표기는 유지합니다.
원본 게임 파일 대신 변경 차이 파일과 설치·제거 도구만 포함합니다.

검수 범위
번역 위치 1,833곳과 코드 25곳을 파일에서 대조했습니다.
제작 중 실제 게임에서 메뉴·설정·진행·상점·툴팁·승리·해금 화면을
확인했습니다. 사용자 요청에 따라 추가 플레이 검수와 설치 실패 상황의
반복 시험을 수행하지 않았습니다. 최종 후보의 모든 화면·전체 분기를 끝까지
검증한 것은 아닙니다. 최종 파일 대조와 차이 파일 복원은 확인했습니다.
1.0.1의 설치기 확인 결과는 ZIP 외부의 결과 보고서에 별도 기록합니다.
