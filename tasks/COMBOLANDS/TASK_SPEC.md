## 조사와 번역

- 자체 `LocalizedStringAsset.GetText()`의 `_originalString` 1,087개 비어 있지 않은 문구와 비어 있는 객체 1개 조사.
- 11개 기본 자산 파일, 모든 장면·프리팹·표시 필드·TextAsset·TMP/UGUI·Odin 저장 자료 조사.
- `Assembly-CSharp.dll`의 메서드·명령 위치별 문자열 620개, 실행 중 조합 문구·표시 enum·다른 게임 어셈블리도 조사한다.
- 이미지·영상은 해시와 위치별로 검토한다. 게임 제목·제작사·기여자 고유명은 유지하되 개별 근거를 기록한다.
- `StringProcessor`에서 대괄호는 아이콘·수치 치환, `@`는 줄바꿈, 중괄호는 강조다. 숫자 자리표시자 `{0}`와 강조용 중괄호를 구분한다. 토큰 뒤 조사가 원래 처리 과정에서 사라지지 않도록 코드와 실제 화면을 함께 검증한다.
- 새 항목과 추출 실패는 UNKNOWN. 추출 실패를 근거 없이 제외하지 않는다.
- 글꼴은 Noto Sans KR의 굵기 600 정적 인스턴스를 사용한다. 라이선스와 원본·생성 파일 지문을 기록한다. 모든 TMP 글꼴의 원본 참조·동적 생성·다중 아틀라스를 검사한다.

## 위험 시험과 실행 검수

- 생성 도구의 기본 활성 플래그 정렬, string[] 구조 표기를 게임 전용 도구에서 보정했다. 수정 대상 객체는 무변경 재직렬화의 바이트 일치와 저장 후 재열기로 독립 대조한다.
- `ObjectReader.get_raw_data()`는 수정 후에도 원본을 반환하므로 `.data`와 저장 후 객체를 대조한다.
- 검수용 DLL은 `SteamManager.Awake`만 무동작 처리하고 `IO.StateSaver.get_PATH`를 작업 공간 저장 폴더로 바꾼다. 정식 후보에는 포함하지 않는다.
- 검수용 `PlayerSettings` 회사명·제품명과 `app.info`를 모두 바꾼다. 첫 시험에서 제품명 변경만으로 기본 로그 경로가 분리되지 않는 것을 확인했으므로 app.info를 추가 격리한다. 당시 생성된 원래 경로의 로그와 생성 시각을 보관하며 저장 게임 파일은 발견되지 않았다.
- 실제 프로세스 경로·PID·후보 지문·그래픽 장치·화면 캡처·로그를 연결한다. 샌드박스에서 실행한 비표시 창은 화면 검수 증거로 쓰지 않는다.
- 첫 화면, 설정, 새 게임, 건물 선택·배치·아이템·툴팁·목표·도움말, 일시정지, 실패·승리·진행 해금·종료 화면을 제작자가 확인한다. 미도달 화면은 NOT_RUN으로 남긴다.
- 저장·설정·Steam 사용자 데이터·로그는 실행 전후 목록과 SHA-256을 비교한다. 필수 화면 미검증 또는 글리프·패치 고유 로딩 오류가 남으면 배포하지 않는다.

## 완료 조건

공통 [핵심 지침서](../../docs/KOREAN_PATCH_PLAYBOOK.md)의 G0~G8을 적용한다. 위치별 번역 대조, 객체 경계 비교, 필요 글자 검사, 실제 화면 검수를 별도로 수행한다. 최종 ZIP에서 추출한 설치기로 설치·중복·부분 설치·제거·변조 거부·실패 및 중단 복구를 검증한다.

## 2026-09-07 최종 범위와 완료 기록

- 사용자는 추가 테스트가 무의미하다고 판단한다고 알린 뒤 “굳이 그럴 필요없고 그냥 완성해주세요.”라고 요청했다. 이 후속 요청에 따라 추가 플레이 검수와 설치 실패 상황의 확장 시험을 중단하고, 최종 패키지 제작과 이미 요청한 실제 적용을 마쳤다. 기존 문서의 추가 검수 조건을 새 승인 절차로 요구하지 않았다.
- 최종 후보 `ko_v010_c11`: 자산 문구 1,833곳(번역 1,800·유지 33), 코드 문구 25곳(게임 17·의견 양식 8), 객체 21,115개 대조 PASS. 글꼴 자산 7개·원본 글꼴 7개·텍스트 참조 609곳 검사 PASS.
