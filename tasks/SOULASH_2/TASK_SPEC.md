## 목표와 범위

사용자가 지정한 Soulash 2의 한국어 패치를 REA로 조사하고 제작한다. 기준은 [핵심 지침서](../../docs/KOREAN_PATCH_PLAYBOOK.md)와 [런타임 QA 참조](../../docs/KOREAN_PATCH_RUNTIME_QA_REFERENCE.md)다. 원본 설치 폴더에서는 읽기만 수행한다. 패치 제작·격리 검증·설치기 준비가 요청 범위이며 Steam Workshop 공개는 요청되지 않았다.

## 기준선

- Windows x64, Steam 앱 2399160, 빌드 25967323, 표시 버전 0.10.4.0.1.
- 네이티브 실행 파일과 SDL2/OpenGL/SDL2_ttf를 사용한다. Unity Mono·IL2CPP·Addressables는 발견되지 않았다.
- 원본: `source_original/SOULASH_2/0.10.4.0.1_20261029`.
- 원본 목록: `extracted_private/SOULASH_2/0.10.4.0.1_20261029/baseline_manifest.json`.
- 추출·REA 원시 증거는 같은 `extracted_private` 아래, 번역·실행 사본은 `working_private/SOULASH_2` 아래에 둔다.
- 후보는 `build_candidate/SOULASH_2/<고유 후보 ID>`에 생성하며 이전 후보를 덮어쓰지 않는다.

## 조사·변경 경계

영어 core_2 JSON 전체, 번역 슬롯, 실행 파일 문자열·참조, 글꼴 자산, 이미지·영상과 도움말·오류·개발 화면을 조사한다. 새 위치는 UNKNOWN이며 근거 없이 제외하지 않는다. 폴란드어 번역의 배열 순서는 현 영어와 다르므로 영어 원본의 식별자를 기준으로 대응한다.

변경은 표시 문구, 언어 메타데이터, 한국어 글꼴과 필요한 표시 코드에 한정한다. 게임 규칙·수치·식별자·저장 형식을 바꾸지 않는다. JSON 파일과 필드 경로, 식별자, 원본 해시를 번역 원본에 연결하고 후보를 별도로 읽어 대조한다. `{}` 서식과 `[color=…]…[/color]` 등 제어 요소의 순서·중첩을 검사한다.

확인된 적용 경로는 core_2 영어 JSON을 번역하고 기존 en 식별자를 유지하는 방식이다. 언어 표시 이름은 한국어로 바꿀 예정이다. 내장 pl 슬롯은 별도 선택 언어로 보존하며 폴란드어 문구를 한국어 번역의 원본으로 사용하지 않는다.

## 글꼴·실행 계획

대량 번역에 앞서 변경 없는 JSON 재저장과 소규모 한국어 로딩을 확인한다. 실제 사용 Romulus와 Lato 글꼴에는 한글 음절이 없으므로 재배포 가능한 한국어 글꼴을 검토한다. 전체 필요 문자와 실제 렌더링을 각각 확인한다.

REA에서 확인한 실제 저장 인자는 WizardsOfTheCode/Soulash2(공백 없음)다. 문서의 공백 있는 경로와 실제 경로를 함께 감시한다. 검수 사본은 별도 작업 폴더·저장 경로와 Steam/오류 보고/업데이트 호출의 제한된 QA 전용 변경을 사용했다. 실제 프로세스 경로·해시와 사용자 저장 전후 무변경을 수집했다. 검수용 코드 변경은 배포본에 넣지 않는다.

필수 화면은 첫 화면, 설정·언어, 새 게임·불러오기, HUD·알림·툴팁, 대화·선택지, 일시정지·도움말, 사망·결과·종료다. 미도달 화면을 제외 처리하지 않는다.
