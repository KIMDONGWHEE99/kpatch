# Soulash 2 번역 기준

## 문체

메뉴·능력·물건 이름은 간결한 명사형을 쓴다. 도움말과 시스템 안내는 자연스러운 존댓말, 물건·세계관 설명은 담백한 서술형을 기본으로 한다. 대사는 화자의 태도와 문맥을 보존한다. 원문의 부정·조건·수치·대상과 단위를 빠뜨리지 않는다.

인명은 문맥에 맞춰 음역하고 일반적인 지형·건물·직업·물건 이름은 번역한다. 조합으로 생성되는 이름은 이름 구성 규칙을 확인한 뒤 일관되게 처리한다. 식별자나 저장 키는 번역하지 않는다. 표시 여부가 불명확한 값은 UNKNOWN을 유지한다.

## 제어 정보

`{}`·`{:.0f}` 같은 값 삽입 자리는 원래 인수 순서를 유지한다. 명시적 번호로 어순을 바꾸는 기능은 실제 형식 처리 코드를 확인하기 전 사용하지 않는다. `[color=…]…[/color]`의 색상·속성·중첩과 제어 줄바꿈을 보존한다. 단축키와 대소문자를 유지하며 실제 키 문자를 뜻하는 부분을 한국어 발음으로 바꾸지 않는다.

번역 파일은 위치 ID와 원문 지문을 갖춘 비공개 공식 번역 원본에서 생성한다. 중복 문구도 화면 문맥이 다르면 분리한다. 자동 처리·사전 치환으로 작성한 부분은 문맥 교정 전 완료로 집계하지 않는다.
