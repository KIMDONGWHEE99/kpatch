다른 빌드나 원본이 변조된 파일에는 적용하지 않습니다.

설치
1. 게임을 종료하고 ZIP을 모두 풀어 주세요.
2. Install.cmd를 실행하고 Soulash 2.exe가 있는 게임 폴더를 선택하세요.
3. 완료 안내를 확인한 뒤 Steam에서 게임을 실행하세요.

제거와 중단 복구
Remove.cmd를 실행하고 같은 게임 폴더를 선택하면 원본으로 돌아갑니다.
설치나 제거 도중 중단됐다면 같은 설치기를 다시 실행하세요.
완료 전에는 다음 백업·복구 기록 폴더를 직접 지우지 마세요.
%LOCALAPPDATA%\Soulash2KoreanPatch\working_private
게임 업데이트 후에는 해당 빌드용 새 패치가 필요합니다.
