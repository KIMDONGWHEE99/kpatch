Kingdom Inc. Demo 한국어 패치 1.0.0

지원 게임
Windows Steam 앱 4702410 / 빌드 25631786 / Demo v0.9.2
다른 빌드나 파일이 바뀐 게임에는 적용하지 않습니다.

설치
1. 게임을 종료하고 이 ZIP을 모두 풀어 주세요.
2. Install.cmd를 실행하고 KingdomInc.exe가 있는 게임 폴더를 선택하세요.
3. 설치 완료 안내가 나온 뒤 평소처럼 Steam에서 게임을 실행하세요.
별도 언어 선택 없이 한국어로 표시됩니다.

제거와 중단 복구
Remove.cmd를 실행하고 같은 게임 폴더를 선택하면 원래 파일로 돌아갑니다.
설치 도중 멈췄다면 같은 설치기를 다시 실행하세요.
백업과 복구 기록은 다음 위치에 있습니다.
%LOCALAPPDATA%\KingdomIncKoreanPatch\working_private
이 기록은 설치나 제거가 끝날 때까지 직접 지우지 마세요.
Steam 업데이트 후에는 새 빌드에 맞는 패치가 필요합니다.

변경 범위
기본 번역표 1,556행과 원본에서 누락된 표시 키 6개,
별도로 들어 있던 문구 154곳과 코드 문구 4곳을 처리했습니다.
한글 글꼴, 글상자 아이콘과 긴 연구 카드 설명의 배치를 포함합니다.
게임 규칙·수치·저장 형식·업적은 바꾸지 않습니다.

유지한 표기
Kingdom Inc.와 Leaping Turtle 로고·제작사명·Tom 서명,
게임이 생성하는 인물 이름, 물리 키 이름, 자동저장 실제 파일명,
K/M/B/T 등 큰 수 단위와 숫자·좌표·기호는 원형을 유지합니다.
데모에 남아 있는 미구현 기능의 문구도 번역했지만
없는 기능을 새로 추가하지는 않습니다.

검사 범위
번역 위치와 글꼴 연결, 실제 대표 화면, 저장·불러오기,
최종 ZIP 설치·제거·중단 복구의 결과는 같은 ZIP의 내용 지문을
명시한 결과 보고서에 기록합니다. 모든 무작위 조합이나 전체 회차를
끝까지 플레이했다는 의미는 아닙니다.
검수용 화면 진입 코드와 검수 저장은 설치 파일에 들어 있지 않습니다.
