# Kingdom Inc. Demo 한글패치 작업 명세

작성일: 2026-10-20

- 요청: 지정된 Steam 설치본의 한글패치 제작과 적용. 화면은 절반 이하로 사용하고 사용자의 작업을 방해하지 않는다.
- 대상: Windows, Steam 4702410 / 빌드 25631786, Unity 6000.3.2f1, Mono.
- 원본은 읽기 전용으로 조사하고 `source_original/KINGDOM_INC_DEMO/steam_25631786/game`에 해시가 같은 사본을 둔다.
- 추출·번역·검수 자료는 `extracted_private/KINGDOM_INC_DEMO` 및 `working_private/KINGDOM_INC_DEMO`, 후보는 `build_candidate/KINGDOM_INC_DEMO`에 둔다.
- 문구와 한글 출력에 필요한 자산만 변경한다. 게임 규칙·수치·저장 형식·업적은 변경하지 않는다.
- 검수용 저장 분리·외부 연동 차단·화면 진입 보조는 검수 사본에만 적용하고 메서드·필드별 차이를 기록한다.
- 실제 게임 설치는 최종 검증 뒤 요청된 폴더에 수행한다. 인터넷 공개는 요청되지 않았다.

## 조사와 검증 계획

공통 [핵심 지침서](../../docs/KOREAN_PATCH_PLAYBOOK.md)와 [실행 검수 참조](../../docs/KOREAN_PATCH_RUNTIME_QA_REFERENCE.md)를 따른다.

1. 모든 파일의 크기·SHA-256(내용 지문)을 고정하고, 문자열·객체·코드·이미지·글꼴을 위치별로 조사한다.
2. 새 항목은 UNKNOWN으로 두고 표시 여부와 원문 해시를 근거로 분류한다.
3. 대량 번역 전에 자산 재저장과 소규모 한글 출력·로딩을 시험한다.
4. 실제 사용 글꼴과 재질을 추적하고, 전체 필요 글자·동적 생성·다중 아틀라스(글자 이미지 저장 공간)를 검사한다.
5. 후보를 별도로 다시 읽어 위치별 번역과 예상 밖 변경을 검사한다.
6. 저장·설정·로그·Steam 쓰기를 분리한 후 실제 후보 실행 경로와 해시를 확보한다.
7. 첫 화면·메뉴·설정·새 게임·HUD·도움말·대화·결과·종료의 존재 여부와 진입 경로를 조사하고 실제 그래픽으로 검수한다.
8. 화면은 절반 이하의 작은 창으로 제한하고 소리를 끈다. 사용자의 마우스·키보드와 경쟁하는 조작은 하지 않는다.
9. 검증된 후보로 차이 패치를 만들고 정·역 복원과 최종 ZIP에서 꺼낸 설치기의 설치·제거·중단 복구를 시험한다.

## 현재 상태

원본 191파일·205,786,393바이트를 내용 지문이 같은 사본으로 보존했다. 자산 문자열 29,399위치, 게임 코드 문자열 3,136위치와 미디어 1,021객체를 분류하고 추출 실패 5건을 해결했다.

소규모 `probe05`에서 실제 GPU의 첫 화면·설정·키 설정·메뉴 복귀를 확인했다. 한글 글자 이미지와 재질 연결을 수정한 뒤 글꼴 경고·오류 0건, 사용자 저장·설정·Steam 상태 무변경을 확인했다. 이 결과는 소규모 기술 시험이며 전체 한글화 완료가 아니다.

번역표 1,556행과 누락 표시 키 6개, 직접 문구 154위치·코드 문구 4위치, 두 크기의 글상자 아이콘과 연구 카드 배치를 처리했다. 최종 후보 rc5의 독립 재추출과 변경 경계·서식·828자 글꼴 검사를 통과했다.

필수 대표 화면군과 저장·불러오기·정상 종료, 원본 비교와 사용자 저장 격리를 확인했다. 최종 ZIP r2에서 꺼낸 설치기로 설치·제거·중단 복구 등 43개 시험을 통과한 뒤 지정 Steam 폴더에 적용했다. 설치본 191파일·원본 백업 8개·사용자 저장 및 설정 무변경을 확인했다.

G0~G8은 [최종 결과 보고서](../../validation/KINGDOM_INC_DEMO/ko_1.0.0/RESULT_REPORT.md)에 명시한 범위에서 PASS다. 전체 회차 완주·모든 무작위 조합·정상 플레이를 통한 모든 기술 해금·전 문구의 실화면 관찰·사용자 설치본 재실행은 NOT_RUN이다. 생성 인명·로고 등 유지 범위와 미구현 화면의 근거를 별도 보고했다. 외부 공개 업로드는 하지 않았다.
