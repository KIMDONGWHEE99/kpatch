## 그래픽 검수 접근

제작자가 실제 Direct3D11 그래픽 장치의 게임 사본에서 필요한 화면을 확인했습니다. 검수 전용 드라이버로 실제 UI 표시 함수를 호출하고 화면을 캡처한 뒤 육안 판독했습니다. 배치 실행은 사용하지 않았습니다. 대사 자료는 후보에서 다시 추출하여 게임의 대화 표시기로 재생했고, 도움말 위치·해금·999레벨 장비·일시정지는 검수 사본에만 적용했습니다. 드라이버는 배포본에 없습니다.

회사·제품 식별자와 EasySave 저장 경로를 검수 전용으로 분리하고 Steam 초기화만 중단했습니다. 원본/후보 코드와 비교하여 검수 사본의 변경이 `SteamHelper.Initialize` 한 메서드 및 선언된 설정 필드로 제한됨을 확인했습니다. 실행 전후와 실제 설치 전후의 사용자 저장·설정은 동일했습니다.
