# Agromatic Demo 한국어 패치 1.0.0

Steam 빌드 25850896의 한글패치를 제작해 사용자가 지정한 `D:\steam\steamapps\common\AgromaticDemo`에 적용했습니다. 문구·한국어 글꼴과 글자가 있는 아이콘 3개를 수정했습니다. 게임·제작사 로고, 고유 인명과 선체의 CARGO 장식은 유지합니다.

- 최종 후보 `ko_v100_c07`: 기대 번역 14,385곳을 독립 재추출로 대조했습니다. 교체 파일은 실행 파일 1개입니다.
- 실제 대표 화면 22단계와 최종 후보의 새 게임·저장·불러오기·정상 종료를 확인했습니다.
- 사용자의 “그만 검수하고 마무리하세요” 지시에 따라 추가 검수를 중단했습니다. 대화 선택 후 결과·전체 회차·전체 분기·오디오 전수 청취·최종 ZIP 확장 설치/복구 시험은 미완료입니다. G0~G8 전체 통과를 선언하지 않습니다.
- 최종 ZIP에서 추출한 설치기로 실제 적용했습니다. 설치본 192파일, 원본 백업 1개, 기록한 기존 저장 위치 보존을 확인했습니다. 설치본을 다시 실행하는 검수는 하지 않았습니다.

[패치 ZIP](../../release_output/AGROMATIC_DEMO_KOREAN_PATCH_1.0.0_r1.zip), [결과와 확인 범위](../../validation/AGROMATIC_DEMO/ko_1.0.0/RESULT_REPORT.md), [작업 명세](TASK_SPEC.md).
