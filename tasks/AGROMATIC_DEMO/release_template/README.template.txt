Agromatic Demo 한국어 패치 1.0.0

지원 게임

이 패치는 Windows 64비트용 Agromatic Demo v0.5.7 전용입니다.
Steam 앱 번호: 4252500
Steam 빌드 번호: 25850896

설치기는 원본 파일 192개의 내용을 모두 확인합니다. 지원하는 원본이나
이 패치가 적용된 상태만 허용하며, 다른 빌드·변조·누락·손상은 거부합니다.
실제로 교체하는 게임 파일은 AgromaticDemo.exe 1개입니다.

번역 범위

화면과 도구 설명, 건물·아이템·연구 설명, 계약, 편지, 대화, 도움말과
게임 중 조합되는 표시 문구를 한국어로 옮겼습니다. 한국어 글꼴을 연결하고
글자가 들어 있는 안내 아이콘 3개도 바꿨습니다. ‘가득’ 아이콘 두 개와
‘구매’ 아이콘 한 개입니다.

일꾼의 이름과 실제 기술 식별자·코드 표기는 유지합니다. Agromatic와
Gimcraft 로고, 배에 장식으로 적힌 CARGO도 원래 그림을 유지합니다.

설치

1. 게임을 완전히 종료합니다. 실행 중인 게임에는 설치할 수 없습니다.
2. 받은 ZIP을 폴더에 모두 풉니다. ZIP 안에서 설치기를 바로 실행하지 마세요.
3. Install.cmd를 더블클릭합니다.
4. 설치기가 찾은 게임 폴더를 확인하고 [설치]를 누릅니다.
   다른 곳에 설치했다면 [찾아보기…]에서 AgromaticDemo.exe가 있는 폴더를
   선택합니다.
5. ‘한글패치 적용 완료’가 표시되면 Steam에서 평소처럼 게임을 실행합니다.

이미 같은 패치가 설치되어 있으면 다시 실행해도 중복으로 바꾸지 않습니다.
설치·제거 과정은 게임 저장, 설정, Steam 업적을 변경하지 않습니다.

제거

게임을 종료한 뒤 같은 패키지의 Remove.cmd를 실행하고 [제거]를 누릅니다.
‘원본 복원 완료’가 표시되면 제거가 끝납니다. 원본 백업이 없어도 지원하는
패치 상태라면 함께 제공한 복원용 차이 파일로 원본을 되살립니다.
이미 제거한 상태에서 다시 제거해도 원본 파일을 그대로 유지합니다.

설치 실패 또는 중단 후 복구

설치기는 파일을 바꾸기 전에 원본 백업과 복구 기록을 준비합니다.
파일 교체나 완료 기록 저장에 실패하면 설치 전 상태로 되돌립니다.

창을 강제로 닫았거나 컴퓨터가 중간에 꺼졌다면 게임을 실행하지 말고,
같은 패키지의 Install.cmd를 다시 실행하세요. 남아 있는 기록을 확인해
중단된 작업을 설치 전 상태로 복원한 뒤 설치를 진행합니다.

‘파일이 사용 중’이라는 오류가 나오면 게임과 해당 파일을 사용하는
프로그램을 닫고 같은 설치기를 다시 실행하세요. ‘복구 기록을 보존했습니다’
라는 안내가 나오면 백업을 지우지 말고 같은 설치기로 다시 복구하세요.

원본이나 백업의 내용이 달라졌다면 강제로 덮어쓰지 않습니다. 지원하지
않는 빌드라는 안내가 나오면 게임 빌드를 확인하고 해당 빌드용 패치를
사용해야 합니다.

백업과 복구 기록은 아래 폴더에 게임 설치 경로·빌드별로 보관합니다.
%LOCALAPPDATA%\AgromaticKoreanPatch\working_private
이 경로를 Windows 탐색기의 주소창에 붙여 넣으면 폴더를 열 수 있습니다.

검수 범위와 지원 정본

배포 후보 번호: @CANDIDATE_ID@
AgromaticDemo.exe SHA-256(파일 내용 지문):
@CANDIDATE_SHA256@

실제 그래픽 장치에서 확인한 화면·흐름:
@QA_CONFIRMED_SCOPE@

이 확인 범위와 데모 전체 회차 검증은 구분합니다. 데모 전체 기간과
모든 이야기 분기·계약·제작 조합을 끝까지 진행한 검증은 수행하지 않았습니다.

최종 ZIP에서 꺼낸 설치·제거기의 정상 설치, 중복 설치, 제거, 손상·미지원
파일 거부, 파일 잠금, 중간 실패와 강제 중단 복구 결과는 ZIP 밖의 최종
검수 보고서에 기록합니다. 그 보고서의 ZIP SHA-256으로 같은 파일인지
확인할 수 있습니다.

패키지 구성과 라이선스

ZIP에는 설치·제거기, 차이 적용 도구, 정방향·역방향 차이 파일, 지원 파일
목록, 이 안내문과 라이선스만 포함합니다. 원본 게임 자산, 추출·역분석 자료,
검수 도우미, 게임 저장 원문은 포함하지 않습니다. 공개 안내와 최종 검수
보고서에도 개인 저장 원문이나 비공개 게임 자산을 싣지 않습니다.
