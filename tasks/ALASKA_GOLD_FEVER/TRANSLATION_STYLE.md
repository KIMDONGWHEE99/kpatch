# 한국어 교정 기준

- 메뉴·버튼·항목 이름은 짧고 익숙한 한국어를 사용합니다.
- 퀘스트 목표는 행동을 명확히 드러내는 `~하기`로 통일합니다. 필요한 대상·수량·순서·조건을 생략하지 않습니다.
- 튜토리얼은 자연스러운 존댓말로 씁니다. `~할 수 있습니다`를 불필요하게 반복하지 않고 동작을 직접 안내합니다.
- 대화·편지는 화자와 관계를 확인한 뒤 말투를 정합니다. 기계적으로 모든 문장을 같은 종결형으로 바꾸지 않습니다.
- 이미 자연스럽고 정확한 문구는 유지합니다. 단어를 바꾼 수로 품질을 평가하지 않습니다.
- 태그·입력 이름·자리표시자·제어 줄바꿈·수치·조건·부정 의미를 보존합니다. 원문 자체의 태그 결함은 위치를 지정해 별도로 기록합니다.

| 영어 | 기본 표기 | 문맥 기준 |
|---|---|---|
| Gold | 금 | 광물·채굴 자원. 금전 가격과 구분 |
| Plot | 부지 | 토지·건설 구역인 경우. 실제 기능 확인 후 적용 |
| Magnetite | 자철석 | 광물명. 자석과 구분 |
| Mine | 광산 / 채굴하기 | 장소와 행동을 구분 |
| Mine shaft | 갱도 | 지지대로 보강하는 통로 |
| Support beam | 지지대 | 갱도 보강 부재 |
| Gold pan | 사금 채취 접시 | 채취 도구의 기능을 드러내는 명칭 |
| Grinding wheel | 숫돌 | 기계식 숫돌을 포함. 대화와 안내문 동일 표기 |
| Oil lamp / Lamp oil | 기름등 / 등유 | 조명 도구와 연료 구분 |
| Reverend | 목사 / 목사님 | 직업명은 목사, 대화와 목표의 인물 호칭은 목사님 |
| Uncle Ben | 벤 삼촌 | 인물 이름을 누락하지 않음 |
| Carpenter | 목수 | 직업 |
| Craftsman | 장인 | 제작·제련 담당 인물. 목수와 구분 |
| Reception | 로비 / 접수대 | 호텔 공간인지 가구인지 문맥으로 구분 |
| Riverside Mine | 강가 광산 | 기존 지명 유지 |
| Abandoned Mine | 폐광 | 영어 원문에 없는 침수 상태를 덧붙이지 않음 |
| Bandits | 산적 | 기존 DLC 명칭과 일치 |
| Winchester | 윈체스터 | 총기 고유명칭 유지 |

이 표는 문맥 판단을 대신하는 일괄 치환표가 아닙니다. 교정자는 영어와 주변 항목을 읽고 적용합니다.
