# Agromatic 작업 파일 공간 정리

작성일: 2026-10-11 · 사용자 요청: 이번 한글패치에 사용한 게임 파일을 삭제하고 다음 패치 개선 자료는 보존.

게임 사본·중간 자산·중복 시험 출력 21,988파일을 삭제했습니다. 파일 크기 합계는 4,969,810,789바이트(약 4.97GB, 4.63GiB)입니다. C 드라이브의 실제 여유 공간은 5,011,779,584바이트(약 5.01GB, 4.67GiB) 증가했습니다. 이 수치는 작업 전후 디스크 여유 공간의 차이이며 같은 시점의 다른 활동에 영향을 받을 수 있습니다.

## 삭제 범위

- 원본 게임의 작업용 사본과 c03~c07 제작 과정의 실행·추출·복원·재저장·컴파일 자산.
- 한국어 및 영어 비교 검수용 게임 사본, 위험 시험 사본, 독립 재추출한 게임 자산과 중복 글꼴 출력.
- 차이 파일 시험에서 복원한 전체 실행 파일 2개, 원본 그림 추출물과 재생성 가능한 아이콘 중복 출력.
- 반복 합성 설치 시험의 큰 사본 154개와 게임 실행 그래픽 캐시. 합성 시험의 핵심 입력·제작 도구·패키지·오류 사례 기록은 보존했습니다.

삭제 경로 305곳은 모두 이번 게임의 원본·추출·후보·비공개 작업 영역 안에 있는지 확인했습니다. 연결 경로를 거부하고, 정리 목록을 만든 뒤 내용이 달라진 대상은 삭제하지 않도록 했습니다. 삭제 자체와 경로 점검은 같은 PowerShell 환경에서 수행했습니다.

## 보존 자료와 확인

번역 원본과 용어·문맥 변환 자료, 게임 빌드·원본 및 후보 해시 목록, 위치별 기대 번역, 분류·미디어 판정과 추출 오류 기록, 글꼴 검사 결과, 수정 원인·교훈과 제작 도구를 남겼습니다. 실제 검수 캡처·화면 진단·실행 경로·로그·격리된 저장·사용자 저장 전후 목록, 설치 시험의 완료·복구 기록도 보존했습니다.

스팀 설치본, 실제 원본 복구 백업, 최종 패치 ZIP·풀어 놓은 설치/제거기와 라이선스는 보존했습니다. 남길 자료와 설치본·복구 백업을 포함한 1,834파일의 내용 지문이 삭제 전후 같았습니다. 다른 게임 작업의 38,453파일은 존재·크기·수정 시각이 같았습니다. 정리 중 게임을 실행하거나 새로운 게임 검수를 수행하지 않았습니다.

## 재작업 기준

게임 사본이 없으므로 지금 남은 폴더만으로 기존 검수를 다시 실행할 수는 없습니다. 다시 제작하거나 게임이 업데이트되면 원본 게임을 별도 사본으로 확보하고, 남긴 전체 원본 목록의 지원 빌드·크기·해시를 먼저 대조해야 합니다. 삭제 전에 기록한 통과 결과는 당시 후보의 이력이며 새 게임이나 새 후보의 통과 근거가 아닙니다.

공통 개선 목록의 미구현 항목을 이 정리나 교훈 문서 작성으로 완료 처리하지 않았습니다. 개인 경로·저장 원문·게임 자산은 이 공개 요약에 포함하지 않습니다.
