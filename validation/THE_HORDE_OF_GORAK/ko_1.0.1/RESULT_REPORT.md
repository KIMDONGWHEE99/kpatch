사용자의 최신 “화면 검수는 여기까지 하고 마무리해주세요” 요청을 반영했습니다. 전체 검수 통과판으로 표시하지 않습니다. 상점은 데이터 번역·글꼴·변경 경계 검사를 통과했지만 실제 표시와 구매 흐름을 확인한 것으로 확대하지 않습니다. 검수용 저장이나 장면 이동, 외부 연동 차단 코드는 배포하지 않습니다.

검수에서 창 플래그를 바꾼 원본과 후보가 같은 `mmfs2.dll+0x1f759` 오류를 보였습니다. 원래 플래그를 유지한 배포 후보는 정상 실행했습니다. REA의 Ghidra12.1.4로 실제 함수 `0x1001f750`의 코드를 분석해 객체 정리 중 포인터 접근임을 확인했으나 최초 초기화 실패 원인을 확정하지 않았고 엔진 코드를 추가 수정하지 않았습니다. REA는 실행 전 저장·Steam 연동 격리 및 실제 실행 경로 관측에도 사용했습니다. 정확한 후보의 정상 실행 기록에 REA 스크립트 오류·접근 위반은0건입니다.

설치기 시험의 실행 중 거부용 모형은 게임 EXE 대신 대기 프로그램을 쓴 상태였습니다. 검사 도구가 모형의 지문을 원래 게임 지문과 비교하여 실패한 것을 수정했습니다. 동일 ZIP·설치기·원본에 대한 영향 없는45개 통과 기록을 보존하고 남은 실행 중 거부·경로 탐색2개를 다시 수행했습니다. 실패 기록은 삭제하지 않았습니다.

ZIP의 `REVIEW_STATUS.json`은 패키지 생성 시점 기록으로 G7이 NOT_RUN입니다. 그 ZIP을 이후 시험한 최종 결과는 [공개 검증 요약](PUBLIC_VERIFICATION.json)에 있습니다.
