- 메시지, 대화, 기술·능력, 물건 설명, 장소·정착지·국가·회사 이름과 인명 목록을 반영했습니다.

- 실행 파일의 직접 표시 문구 9곳과 직업·종족 이름 출력 6곳을 수정했습니다. 데이터의 `None`과 종족 식별자는 유지하고 화면 출력만 바꿉니다.
- 저장 형식에도 쓰이는 구성요소 이름 78개는 원문으로 복원했습니다. 이 이름을 번역한 검수용 저장은 패키지에 포함하지 않습니다.
