## 번역과 변경

원래 언어 표 1,556행, 원본에서 빠져 있던 표시 키 6개, 별도 자산의 문구 154위치, 코드 문구 4위치를 처리했습니다. 한글 글꼴과 두 크기의 글상자 아이콘, 긴 연구 카드 설명의 배치를 포함합니다. 완성된 후보를 별도로 다시 읽어 번역 위치·빈 값·원문 잔존·서식·참조·변경 경계를 대조했습니다.

전체 191파일 중 8파일이 변경됩니다. 게임 규칙·수치·저장 형식·업적은 변경하지 않습니다. 회사·제품명 변경, Steam 차단, 화면 진입 보조와 시험 저장은 검수 사본에만 존재하며 최종 패키지에 포함되지 않습니다.

필요 문자 828자를 계산하고 실제 사용 원본 글꼴 3개, 화면 글꼴 4개, 사용 위치 407곳을 연결했습니다. 실제 그래픽 실행에서도 문자 생성과 대체 글꼴 연결을 검사했고 글리프(글자 모양) 누락 경고는 0건입니다.

## 확인 범위

소규모 기술 시험을 먼저 수행하고, 이후 첫 화면·설정·키 설정·새 게임·수동 제작·게임 상태 표시·건설·연구·장식·인물·전쟁·안내·저장·불러오기·데모 감사·정상 종료의 대표 흐름을 확인했습니다. 코드와 자산에만 남은 예·아니요 공용 선택창과 인물 사망 표기도 별도 검수 사본에서 표시했습니다.

실제 NVIDIA GeForce RTX 4060 Ti에서 1200×900 무음 창으로 실행했습니다. 2560×1440 모니터의 절반 너비 이하를 사용했고 사용자 마우스·키보드를 조작하지 않았습니다. 실행 파일의 실제 경로·후보 내용 지문·창 크기·저장 경로·Steam 비활성 상태를 수집했습니다. 각 실행 전후 사용자 저장·설정·Steam 상태를 비교했습니다.

rc4에서 확인한 영향 없는 화면은 rc4→rc5의 파일·객체·필드·픽셀 차이를 근거로 재사용합니다. rc5의 변경은 언어 표 한 항목과 아이콘의 16×16픽셀 칸뿐이며, 그 밖의 객체 바이트와 파일 189개는 같습니다. rc5에서 수정 영향과 저장·재진입 등 33장을 실제 판독하고 예비 UI 2장을 추가 판독했습니다. 이전 실패 기록은 지우지 않고 후속 해결 근거에 연결했습니다.

실제 판독 자료와 표시 문구를 엄격하게 연결한 결과는 1,716위치 중 193곳입니다. 나머지 1,523곳은 **정적 대조 PASS / 개별 실제 표시 위치 관찰 NOT_RUN**입니다. 숫자가 들어가는 조합 문구와 표시값이 같지만 출처가 여러 개인 문구는 보수적으로 계수했으므로 이 수치를 전체 번역의 가독성 확인 비율로 해석하지 않습니다.

전체 회차 완주, 모든 무작위 조합, 정상 플레이로 모든 기술 해금, 모든 전투 결과와 전 문구의 실제 표시 관찰은 **NOT_RUN**입니다. 사용자 설치본의 추가 실행도 하지 않습니다. 상세 범위와 부재 근거는 [출처·번역 범위](SOURCE_AND_SCOPE.md), [실제 화면 검수](RUNTIME_QA.md)에 있습니다.

## 남긴 표기와 미디어

Kingdom Inc.·Leaping Turtle 로고와 제작사명, Tom 서명, 게임이 생성하는 인물 이름, 물리 키 이름, 자동저장 실제 파일명, K/M/B/T 등의 큰 수 단위와 숫자·기호는 유지합니다. 이름 생성 코드의 문자열 497위치를 조사하고 조합·축약 방식과 고유명사 유지 근거를 기록했습니다. 이 497위치에는 내부 처리값 67곳도 포함되므로 전부 표시되는 인명 조각을 뜻하지 않습니다.

미디어 1,021객체의 현재 분류는 글자 없음 779, 근거 있는 유지 238, 번역 4입니다. 번역 4는 두 그림과 이를 참조하는 두 스프라이트(화면 그림 조각)이며 실제 새 그림 네 장이라는 뜻은 아닙니다. 영상 객체는 없습니다. 공개 요약에는 원본 이미지나 저장 원문을 복사하지 않았습니다.

## 설치·제거와 복구

최종 ZIP에 담긴 설치기로 설치·제거·중복 적용·부분 설치·변조 거부·잠긴 파일·기록 쓰기 실패·강제 중단 후 복구·경로 검사를 포함한 43개 시험을 통과했습니다. 변경 8파일의 정방향·역방향 복원 16회, 허용 파일 25개와 내용 지문도 확인했습니다. 처음 제작한 공개판이므로 이전 공개 패치 업그레이드는 `NOT_APPLICABLE`; 이전 작업 후보 거부는 별도로 시험했습니다. [설치기 검증](INSTALLER_QA.md).

다시 설치하려면 ZIP 전체를 푼 뒤 `Install.cmd`를 실행하고 `KingdomInc.exe`가 있는 폴더를 선택합니다. 제거는 `Remove.cmd`에서 같은 폴더를 선택합니다. 중간에 멈췄다면 같은 설치기를 다시 실행하면 기록에 따라 복구합니다. 지원하지 않는 게임 업데이트나 파일 변경은 강제 적용하지 않습니다.

복구 백업과 거래 기록은 `%LOCALAPPDATA%\KingdomIncKoreanPatch\working_private`에 있습니다. 설치·제거가 끝나기 전에는 이 기록을 지우지 않습니다. 설치 후에는 평소처럼 Steam에서 실행하며 별도 언어 선택이 필요하지 않습니다.
