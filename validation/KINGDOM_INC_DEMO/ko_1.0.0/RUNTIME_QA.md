# Kingdom Inc. Demo 1.0.0 실행 검수

2026-10-20, Steam 빌드 **25631786**, 최종 후보 **1.0.0_rc5**를 대상으로 기재된 **대표 화면 검수(G5)를 통과**했습니다. 전체 회차나 모든 번역 문장을 실제 화면에서 확인했다는 뜻은 아닙니다.

실제 그래픽 장치에서 제작자가 화면을 열고 판독했습니다. 캡처 파일 생성 여부나 텍스트 자동 검사만으로 화면 검수를 통과시키지 않았습니다.

|---|---|---|
| 첫 화면·버전 | 로고, 첫 메뉴, 데모 표시, 버전, 시작 로딩 | PASS |
| 메뉴·설정 | 설정, 키 설정의 위·아래 목록, 게임 중 설정 | PASS |

계획의 **123단계**와 추가 화면 2종에 유효한 증거를 연결했습니다. 상태를 준비하는 명령과 종료 확인도 포함한 단계 수이며, 서로 다른 화면 123개라는 뜻은 아닙니다.

최종 후보에서는 33장을 실제 판독했고, 추가 검수에서는 예·아니요 창과 사망 표시 2장을 판독했습니다. 수정 전 후보의 유효한 검수도 아래의 정확한 차이 비교를 거쳐 재사용했습니다. 전체 판독 기록은 179개 이미지 파일이며, 유효한 PASS 기록 173개와 보존한 이전 FAIL 5개·BLOCKED 1개로 나뉩니다. 추가 실행의 미판독 중간 캡처 5개는 검수 완료 수에 넣지 않았습니다.

## 실행과 저장 보호

- Unity 6000.3.2f1, NVIDIA GeForce RTX 4060 Ti에서 실제 그래픽으로 실행했습니다.
- 2560×1440 모니터에서 1200×900 창을 왼쪽에 배치하고 무음으로 검수했습니다. 운영체제의 마우스·키보드 입력을 사용하지 않았습니다.
- 실제 실행 경로·프로세스 번호·후보 파일의 내용 지문(SHA-256)을 연결했습니다. Steam 설치본 대신 격리한 후보 사본이 실행됐음을 확인했습니다.
- 검수 회사·제품명, 저장 위치, 설정, 로그를 분리하고 Steam 초기화를 차단했습니다. 사용자 저장·설정·Steam 관련 상태의 실행 전후 비교는 모두 동일했습니다.
- 대표 후보 실행, 최종 실행, 추가 실행과 원본 비교 실행 모두 종료를 확인했습니다.
- 검수 지원 코드는 배포 후보에 포함하지 않습니다. 게임 코드의 검수 변경은 시작 보조 호출과 Steam 초기화 차단 두 메서드로 제한하고 516개 형식·3,666개 메서드의 경계를 검사했습니다.

## 글꼴과 오류

전체 번역에 필요한 **828글자**를 실제 글꼴 4개에서 검사했습니다. 동적 글꼴의 실제 글자 생성과 여러 글자 이미지 저장 공간, 기존 정적 글꼴의 한글 대체 흐름까지 확인했으며 최종 누락은 0개였습니다.

최종 및 추가 실행에서 글리프 누락, 글꼴 경고, 게임 오류, 검수 명령 실패는 각각 0건입니다. 수정 전 rc4의 검수 선택자 실패 1건은 실제 인물 슬롯을 지정해 복구했으며, 원래 실패 기록은 남겼습니다.

원본 영문판도 같은 지원 코드로 비교했습니다. 대표 화면 11쌍과 추가 화면 2쌍을 실제로 열어 비교했습니다. 종료 시의 `ComputeBuffer` 정리 경고와 그래픽 초기화의 D3D12 정보 큐 기록은 원본에서도 같은 조건으로 나타났습니다. 이를 패치 고유 오류로 세지 않았으며, 정확한 내부 원인까지 확인했다고 주장하지 않습니다.

## 발견한 문제와 해결

| 이전 문제 | 해결 근거 |
|---|---|
| 기술 목록 진입 오류, 시설 툴팁·산림 탭의 검수 접근 문제 | 검수용 접근만 보완한 뒤 실제 목록·설명·탭과 오류 0건 확인 |
| 기술 카드의 설명과 그림 겹침 | 공용 카드의 배치 3필드만 수정하고 14개 큰 카드 판독 |
| 자원·산림 창이 다른 창에 가림 | 단독 창으로 다시 촬영하고 판독 |
| 작은 글상자 아이콘에 영문 잔존 | 해당 16×16 이미지 셀만 수정하고 카드·목록·꾸미기 재검수 |
| 숫자 입력 안내의 부적절한 번역 | 감정사·회계사의 “가치”를 “값”으로 수정하고 두 창 재검수 |
| 감사 본문 위에 전쟁 알림이 남음 | 원본 공통 현상 확인 후 알림 없는 최종 화면에서 본문 전체 판독 |
| 중복 툴팁 이름 선택, 종료 확인 권한 오류 | 실제 인물 슬롯 지정 및 읽기 전용 프로세스 목록 확인으로 복구 |

rc4에서 rc5로 바뀐 내용은 **언어 표의 `AppraiserValue` 1개와 작은 아이콘의 16×16 이미지 셀**뿐입니다. 나머지 189개 파일과 변경 파일 안의 다른 객체가 같음을 확인했습니다. 두 변경 대상은 최종 후보에서 다시 확인했고, 영향 밖의 화면에만 이전 PASS를 재사용했습니다.

추가 화면을 위한 새 지원 코드도 기존 메서드 123개가 동일하며, 명령 분기 한 곳에 추가한 두 명령 외의 기존 본문이 그대로임을 확인했습니다. 추가 원본과 후보는 이 같은 새 지원 코드로 비교했습니다. 이전 FAIL·BLOCKED 보고서를 수정해 PASS로 바꾸지 않았습니다.

## 적용하지 않는 화면과 확인하지 않은 범위

장면 목록, 실제 메뉴 연결, 게임 코드와 저장된 UI 이벤트를 조사했습니다. 이 데모에는 스토리 대화·분기, 별도 언어 전환·접근성·게임 오버 화면이 없습니다. 언어 관련 함수나 예비 문구가 남아 있다는 이유로 실행 가능한 화면이 있다고 보지 않았습니다. 공용 예·아니요 창과 인물 상세의 사망 표시는 존재하므로 별도로 검수했습니다.

농장·던전과 고단계 정상 해금, 환전 창은 데모의 미등록 기능 또는 연결되지 않은 자산이라는 근거로 실행 대상에서 제외했습니다. 남아 있는 관련 문구는 번역·파일 검사와 전체 글자 생성 검사에 포함했습니다.

화면 내 표시값과 번역 목록을 정확하게 연결한 수는 **1,716위치 중 193위치(11.25%)**입니다. 미관찰 1,523위치는 파일 검사 PASS와 실제 화면 미검수 `NOT_RUN`을 구분해 보존했습니다. 이 수치는 텍스트 연결 범위이며, 모든 문장의 개별 가림 판정이나 전체 번역의 실제 관찰 완료율은 아닙니다. [출처와 범위](SOURCE_AND_SCOPE.md)에 산정 방법을 기록했습니다.

다음은 이 검수의 완료 범위에 포함하지 않습니다.

- 전체 회차·모든 분기·모든 조합과 미관찰 문구의 개별 실제 화면 판독
- 정상 재화 획득·기술 해금·전쟁 승리의 완주
- 실제 전투에서 살아 있는 병사의 사망 전환 및 예비 선택창의 게임 결과
- 모든 해상도·표시 배율 조합
- 사용자 Steam 설치본의 설치 후 실제 그래픽 재실행

설치·제거·복구 시험과 실제 설치 파일 검증은 별도 결과에 따릅니다. 이 문서는 격리 후보의 대표 화면 검수 결과만 판정합니다.

내부 통합 근거는 `runtime_final_resolution.json`이며, 각 화면의 판독 기록·캡처 내용 지문·실행 기록·원본 비교·차이 검사·실패 해결표를 연결했습니다. 원본 게임 자산, 저장 내용, 검수 실행 코드는 이 공개 요약에 포함하지 않았습니다.
