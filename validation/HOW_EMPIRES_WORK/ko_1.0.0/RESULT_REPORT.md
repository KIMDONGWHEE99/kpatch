## 실제 화면 검수 범위

실제 게임 실행 파일을 NVIDIA RTX 4060 Ti의 D3D12 Forward+ 장치에서 실행했다. Steam 실행 전환을 차단한 별도 검수 사본으로 실제 경로와 PCK 지문을 수집했다. 검수용 변경은 Steam 초기화 차단, 저장·로그 격리 설정, 상태·프레임 수집 코드의 4개 묶음 항목으로 제한하고 실제 바이트코드 2개를 다시 풀어 확인했다.

첫 메뉴, 설정 상·중·하단과 언어 선택, 제작진, 새 게임 대화, 명령 설명창, 일시정지, 한글 저장 이름, 불러오기 목록·확인, 본편 HUD, 무역·도로·탐험·주·귀족·제도·생산·과제, 생산 종류와 생산 라인, 발전 계통도, 본편 종료와 영광 모드 점수·결과를 판독했다. 긴 결과 문구는 상단·하단을 스크롤해 확인했다. 최종 수정본에서는 주 생성·한글 저장·재실행·불러오기 및 본편 결과를 다시 확인했다.

초기 일부 화면은 실제 UI로 조작했다. 이후 사용자 조작을 방해하지 않도록 게임 내부 메서드와 해당 창에만 전달하는 입력을 사용하고, 실제 GPU 프레임을 받아 판독했다. 후반 표본은 원작 개발 명령으로 기능을 해금하고 결과 조건으로 진입했다. 전체 회차·모든 분기를 완주한 검수가 아니며, 스크롤 목록은 캡처된 구간의 확인이다.

자동 입력 도구가 Godot 입력란에 한글을 보내지 못해 실제 한국어 입력기 타건은 NOT_RUN이다. 입력란의 한글 이름 표시, 해당 이름으로 실제 저장 처리, 저장 목록·재시작·불러오기, 전체 한글 글리프 검사는 수행했다. 설치 후 실제 Steam 설치본을 추가로 실행하지 않았으며 검수한 최종 후보와 설치 파일의 지문 일치를 확인했다.

## 발견한 문제와 수정

- 기본 설명창이 어두운 글자색을 상속하던 문제: 같은 계열의 테마 8개에 설명창 전용 밝은 글자색을 지정했다. 실제 화면과 최종 테마 재열기로 확인했다.
- 주 이름이 `주수도 근교`로 붙던 문제: 접두어를 `주: `로 보완했다. 주 생성·저장·재시작 후 `주: 수도 근교` 표시를 확인했다.
- 원문의 무역 원정대 자동화 설명에 빠진 색상 닫기 태그 1개를 보완했다. 서식 5,300행의 다른 순서·중첩·아이콘·자리표시자·제어 줄바꿈 차이는 없다.

원본과 후보에서 동일하게 나타나는 Rider 편집기 확장 누락, 발전 자원 UID 대체, 미니맵·과제 정의 경고, 종료 시 자원 정리 경고는 원본 문제로 대조해 기록했다. 경고가 전혀 없는 게임이라고 표시하지 않는다. `.fnt` 내보내기 실패 1개는 원본 FontFile을 직접 열어 검사하는 방법으로 해결했고 폰트 검사에서 제외하지 않았다.
