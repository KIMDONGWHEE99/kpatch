2. **[P1] 일부 정적 검사가 “그 위치에 올바른 번역이 있는가”를 확인하지 않는다.**

   Pibcremental의 직접 표시 문구 검사는 알려진 원문 잔존을 찾고, 번역 목록 안의 한국어가 몇 번 나타나는지 센다. 원본의 각 위치와 후보의 기대 번역을 일대일로 비교하지 않고, 집계한 번역 횟수도 기대 개수와 비교하지 않는다. 따라서 번역 위치를 빈 문자열이나 엉뚱한 값으로 바꾸는 오류는 이 검사만으로 검출되지 않는다. 직렬화 표시 필드에도 원문 잔존 검사 중심의 같은 한계가 있다. 이 항목은 코드 검토로 확인했으며, 실제 후보 자산을 변조하는 시험은 하지 않았다.
